# AI Agent Coordination & Decision Engine

## Project Overview
An AI-powered multi-agent system designed to coordinate specialized agents for business analysis, research, decision-making and recommendations.

## Technology Stack
- Python
- LangChain
- LangGraph
- FastAPI
- PostgreSQL
- ChromaDB
- React
- AWS
