## M1 responsibility
M1 owns overall architecture, common interfaces, GitHub integration coordination, documentation, progress tracking and system-level testing coordination. Each member remains responsible for implementing and independently testing their assigned component.

## How to use these documents
1. Read the architecture documents before implementing integrations.
2. Agree the contracts with M7 before schemas and orchestration are implemented.
3. All members should follow the ownership and Git workflow documents.
4. Update documents when the team formally approves a design change.

## Status and decisions
The technology stack and design in the project specification are proposed. The team should confirm provider choices, database/vector-store details and any deployment costs with the mentor before committing to paid services or cloud resources.
