# Eight-Week Roadmap

## Purpose
This roadmap follows the eight-week schedule in the project specification. It combines individual development with shared integration milestones.

| Week | Individual development focus | Integration milestone |
|---|---|---|
| 1 | All members prepare environments and designs | Architecture and common contracts |
| 2 | M2, M4 and M5 build basic agents; M8 builds UI | Module 1 demonstration |
| 3 | M3 builds tools; other members integrate mock interfaces | Tool execution demonstration |
| 4 | M4 and M5 build specialized agents; M7 builds orchestration | Agent communication demonstration |
| 5 | M6 completes memory; M7 integrates it | Memory integration demonstration |
| 6 | M7 completes workflows; M3/M5 support execution and decisions | Complete business workflow |
| 7 | M7 and M8 complete API/dashboard integration | Full application demonstration |
| 8 | All members test and fix issues | Deployment and final submission |

## M1 weekly responsibilities
| Week | M1 deliverables / coordination |
|---|---|
| 1 | Confirm roles, repository structure, architecture, ownership and common contracts with M7 |
| 2 | Review basic agent interfaces; coordinate first integration demonstration |
| 3 | Coordinate tool interface checks and mock-based integration |
| 4 | Coordinate agent-to-agent communication test with M4, M5 and M7 |
| 5 | Coordinate memory interface integration with M6 and M7 |
| 6 | Track full workflow blockers and coordinate end-to-end testing |
| 7 | Coordinate backend/dashboard integration checks and demonstration readiness |
| 8 | Coordinate final system tests, defect fixes, documentation and submission rehearsal |

## M1 weekly review checklist
At the end of each week:
- [ ] Each member reports completed work and blockers.
- [ ] Changed interfaces are discussed and documented.
- [ ] Relevant tests have been run.
- [ ] Integration branch is updated through reviewed pull requests.
- [ ] Open defects have an owner and target week.
- [ ] Documentation reflects approved changes.

## Critical milestone
The project specification identifies a working end-to-end vertical slice by the end of Week 4 as an important milestone. Integrate progressively; do not postpone all integration until the final weeks.
